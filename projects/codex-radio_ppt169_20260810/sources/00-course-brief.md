# Codex 任务电台课程简报

2026-09-05 修订。案例：《Codex 任务电台：一把键盘，远程开发》；讲者 Lark，
知名外企嵌入式软件与 AI 产品转型负责人。

## 受众与节奏

面向硬件与编程初学者。主讲建议 60 分钟，其中 8-10 分钟展示真机操作；
训练营两小时课时的其余时间可用于分组复现、排错和提问。这是授课建议，不替代活动安排。
本案例复现环境为 macOS + Codex CLI，Windows/Linux 学员可先做原理练习或与 Mac 学员共用设备。

## 为什么做

Lark 同时使用几个 Codex 任务处理固件、App、测试和文档，需要反复切窗口下要求和查看结果。
EasyInput V2 已有八键、五灯、麦克风和扬声器，因此尝试把常用操作放到实体按键上：
上排说要求，下排听总结，灯提示未听结果。需要看代码或处理授权时仍回到电脑。
当前仅实现键盘与 Mac 的同一局域网链路，不宣称已经完成公网遥控。

## 47 页结构

| 页码 | 内容 | 讲清的问题 |
|---|---|---|
| 01-09 | 案例与动机 | 为什么几个任务一起跑，仍会频繁打断人 |
| 10-20 | 硬件、App、按键和灯 | 这块板怎么操作，电脑和固件各做什么 |
| 21-31 | 十个基础概念 | 网络、配置、Flash、音频、认证、版本、队列、完成、播放、后台 |
| 32-38 | 两条链路与开发问题 | 语音如何往返，遇到无声、慢和不亮灯时如何定位 |
| 39-41 | 练习与收束 | 从一个任务跑通开始，再做小改造 |
| 42-47 | 六页技术附录 | 参数、GPIO、时序、数据保存和仓库入口 |

## 表达与素材

- 用具体操作和状态例子解释，不编造独白，不把口号当作结论。
- 真实硬件资料保留完整视野，App 截图脱敏；生成插画明确标识。
- 说明设备到 Mac 走局域网，而 Mac 调用 ASR、Codex、总结和 TTS 仍依赖互联网。
- 任务结束不等于音频就绪；上行认证不等于加密；传输完不等于真正听完。
- 测试、日志、实际按键和听感分别记录。未测试项不填“通过”。
