# DeepSeekHarness KeyBroad 使用手册

> **版本**：v1.0 (Windows + Local DeepSeek Harness)  
> **适用硬件**：ESP32-S3 V2 机械宏键盘（8 键 + 金属旋钮 + 5 RGB 灯 + 板载扬声器/麦克风）  
> **适用系统**：Windows 10 / 11（64-bit）  

---

## 1. 产品简介

**DeepSeekHarness KeyBroad** 是一款将**实体硬件微交互**与**本地 DeepSeek 大模型开发工作流**深度融合的极客智能键盘终端。

通过将 8 个物理机械按键与板载微型电脑（ESP32-S3）相连，结合局域网内运行的本地守护服务（Host）和轻量桌面管理端，你可以实现：
- **盲操语音输入**：无需切屏、无需呼出窗口，按住按键对任意绑定的项目会话直接下达编码与排障指令；
- **全物理状态感知**：键盘顶部的 5 颗 RGB 指示灯以直观的色彩和亮度，实时反馈各任务的排队运行状态与未读成果；
- **免看屏语音播报**：任务完成后，随手轻按一键，板载高品质扬声器便会自动朗读大模型的精炼结论与变更要点；
- **硬件级音量旋钮**：随时旋转调节板载音量，短按即播报当前档位，完全独立于电脑系统音量。

```
┌─────────────────────────────────────────────────────────────────┐
│                    DeepSeekHarness KeyBroad                     │

│   [ 旋钮 ]        [ S1 ]      [ S2 ]      [ S3 ]      [ S4 ]    │  ← 上排：PTT 录音

│                  (听槽 1)    (听槽 2)    (听槽 3)    (听槽 4)   │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 硬件交互与按键语义

键盘物理面板由 **8 颗机械按键**、**1 个带按压的金属旋转编码器旋钮** 以及 **5 颗高亮 RGB 指示灯（WS2812）** 构成。

### 2.1 机械按键（S1 ~ S8）

| 按键序号 | 物理位置 | 核心功能 | 操作说明与交互逻辑 |
|:---:|:---:|:---:|---|
| **S1** | 上排第 1 键 | **槽位 1 · PTT 语音输入** | **按住说话，松开发送**。录音启动并转写为文字后，严格推入槽位 1 绑定的 DeepSeek 任务队列。 |
| **S2** | 上排第 2 键 | **槽位 2 · PTT 语音输入** | **按住说话，松开发送**。录音推入槽位 2 绑定的 DeepSeek 任务队列。 |
| **S3** | 上排第 3 键 | **槽位 3 · PTT 语音输入** | **按住说话，松开发送**。录音推入槽位 3 绑定的 DeepSeek 任务队列。 |
| **S4** | 上排第 4 键 | **槽位 4 · PTT 语音输入** | **按住说话，松开发送**。录音推入槽位 4 绑定的 DeepSeek 任务队列。 |
| **S5** | 下排第 1 键 | **槽位 1 · 播放未读总结** | **短按一次**：板载扬声器朗读槽位 1 最新的执行结果。完整听完后信箱灯熄灭。 |
| **S6** | 下排第 2 键 | **槽位 2 · 播放未读总结** | **短按一次**：朗读槽位 2 最新的执行结果。 |
| **S7** | 下排第 3 键 | **槽位 3 · 播放未读总结** | **短按一次**：朗读槽位 3 最新的执行结果。 |
| **S8** | 下排第 4 键 | **槽位 4 · 播放未读总结** | **短按一次**：朗读槽位 4 最新的执行结果。 |

> **关键机制说明**：
> 1. **PTT 绝对优先抢占**：在任何时候（包括扬声器正在朗读总结时），只要按住上排任意 PTT 键，播放会**瞬间中断**并立即开始录音，确保录音绝不录入系统自身的播报声。
> 2. **未读内容防丢与自动合并**：如果某槽位有未听完的总结，无论中途打断、断电或 DeepSeek 输出了多次连续结果，系统会自动把旧的未听结论与新结论**合并保存**，按 S5~S8 会从头完整播报，不漏任何信息。

### 2.2 旋转编码器旋钮（Volume & Config）

旋钮为无极旋转编码器，并集成了中心按压按键：

- **顺时针旋转（CW）**：增大板载扬声器输出音量。
- **逆时针旋转（CCW）**：减小板载扬声器输出音量。
  - 共分 **10 档平滑增益**（默认出厂为 70%）。
  - 旋转停止 1 秒后，音量值自动写入硬件内部 NVS 存储芯片，**断电重启依然记忆**。
  - **重要特性**：旋钮调节的是**键盘硬件内部 DAC 放大器增益**，不会向 Windows 发送全局多媒体音量键，绝对不干扰电脑正在播放的音乐或视频。
- **短按旋钮**：键盘立即通过板载扬声器**离线播报当前音量**（例如：“当前音量百分之七十”），无需联网。
- **长按旋钮（3 秒）**：进入硬件 Wi-Fi 配网模式（热点配置模式）。

### 2.3 五颗 RGB 状态指示灯（从左至右）

键盘正面的 5 颗灯自左向右排列，其职责划分清晰严谨：

```
 [LED 1]      [LED 2]      [LED 3]      [LED 4]      [LED 5]
 (槽位1信箱)  (槽位2信箱)  (槽位3信箱)  (槽位4信箱)  (全任务运行状态)
```

#### ① 左起第 1 至第 4 颗灯（LED 1 ~ LED 4）—— 四槽未读信箱灯
- **常灭（黑）**：对应槽位当前没有未读的总结语音。
- **常亮（绿光）**：对应槽位有已完成、等待收听的语音成果。未听的变更越多，绿光亮度会**单调渐变增强**。
- **熄灭时机**：只有在用户按下对应的 S5~S8 键，将语音**完整收听完毕**并向 Host 确认后，绿灯才会自动熄灭。

#### ② 最右侧第 5 颗灯（LED 5）—— 任务运行负载灯
LED 5 统一指示当前 4 个槽位绑定的任务中，有多少个任务正在并发执行：
- 🟢 **常亮绿色**：**空闲就绪**（0 个任务在运行，所有任务均已结束）。
- 🟡 **常亮黄色**：当前有 **1 个任务** 正在执行（DeepSeek 思考/跑代码中）。
- 🟠 **常亮橙色**：当前有 **2 个任务** 正在并发执行。
- 🟣 **常亮紫色**：当前有 **3 个任务** 正在并发执行。
- 🔴 **常亮红色**：当前全部 **4 个任务** 均处于满负载运行中。
- 当正在运行的任务执行完毕并生成回复后，LED 5 会随之降档，全部完成自动回绿。

## 3. 快速上手指南

### 3.1 首次使用前准备
1. **网络连接**：确保 DeepSeekHarness KeyBroad 键盘与你的 Windows 电脑连接在**同一个局域网（同一 Wi-Fi）**下；
2. **环境依赖**：
   - 本地已安装并可正常运行 DeepSeek Harness（默认位于 `~/.dsh`，全局可用 `dsh.cmd`）；
   - DashScope 密钥配置：在 `%APPDATA%\EasyCodexInput\.env` 中配置阿里云百炼 API 密钥（用于毫秒级 ASR 语音识别与 TTS 总结合成）：
     ```env
     DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
     ```

### 3.2 一键启动产品
在仓库根目录下，直接双击运行：
👉 **`Start DeepSeekHarness KeyBroad.cmd`**

脚本会自动执行以下流程：
1. 检测 Windows 本地常驻后台服务 `easy-codex-host.exe daemon`；若未启动则自动在后台拉起；
2. 启动桌面管理界面：**`DeepSeekHarness KeyBroad.exe`**；
3. 显示可视化窗口，自动探测已连接的硬件键盘与本地 DeepSeek 任务。

> 💡 **提示**：管理窗口关闭后，后台守护服务仍会持续在后台运行，不会中断键盘的语音通信或任务执行。

## 5. 日常使用工作流示例

### 场景：边写业务逻辑，边让 DeepSeek 排查测试用例

1. **选择绑定会话**：
   - 在桌面端中，将 **槽位 1 (S1)** 绑定到你的 `user-service` 项目，将 **槽位 2 (S2)** 绑定到 `payment-gateway` 项目。
2. **发起指令**：
   - 按住键盘上的 **S1** 键，清晰开口说：“*帮我检查 UserServiceTests 为什么报 NullPointerException，并修复它。*”
   - 说完后**松开 S1 键**。
3. **观察执行状态**：
   - 键盘最右侧的 **LED 5 瞬间变成黄色**（表示 1 个任务正在执行）；
   - 你可以继续在编辑器里做其他事情，完全无需切出窗口。
4. **接收结果通知**：
   - 几十秒后，DeepSeek 修复完成并退出，Host 提取出真实修复摘要并完成语音合成；
   - 键盘最右侧 **LED 5 变回绿色**（执行完毕）；
   - 左侧 **LED 1 亮起绿色**（提示槽位 1 的信箱有新成果到达！）。
5. **收听成果汇报**：
   - 随手轻按一下下排的 **S5** 键；
   - 键盘扬声器传出清晰声音：“*已修复 UserServiceTests。原因是 UserProfile 模拟对象未注入，已补齐 @Mock 声明并添加了单元验证，所有用例测试通过。*”
   - 播报完毕，**LED 1 绿灯自动熄灭**。

## 6. 常见问题排查（FAQ）

### Q1：按下 S1~S4 说话，LED 5 为什么没有变黄？
- **检查键盘连接**：观察桌面端界面的“键盘语音”项是否显示为“已认证”；如果显示“等待连接”，请确认电脑与键盘是否连入**同一 Wi-Fi**，且 Windows 防火墙未阻断 UDP 17333 端口；
- **检查 DashScope 凭据**：观察桌面端界面的“DashScope”板块是否显示绿色“已就绪”；若提示凭据缺失，请检查 `%APPDATA%\EasyCodexInput\.env` 中的 API Key 是否有效。

### Q2：短按 S5~S8 为什么没有声音？
- **检查音量**：顺时针旋转旋钮调大音量，并**短按一下旋钮**听是否有“当前音量百分之...”的提示音；
- **确认是否有未听成果**：只有当左侧对应的 LED 1~4 亮起绿灯时，才表示该槽位有待听的总结；无未读内容时短按不会触发播放。

### Q3：如何重新给键盘配置 Wi-Fi？
- 长按旋钮 **3 秒以上**，键盘会进入 AP 配网模式；
- 用手机或电脑连接键盘发出的 Wi-Fi 配置热点，访问提示的配网页面重新输入家里的 Wi-Fi 名称和密码。

### Q4：关闭桌面管理窗口后，键盘还能正常用吗？
- **可以正常使用**。桌面窗口（`DeepSeekHarness KeyBroad.exe`）只是可视化控制台，核心语音转发、DeepSeek 调度和音频播报均由后台的 `easy-codex-host.exe daemon` 常驻服务提供。关闭窗口丝毫不影响硬件按键与语音功能。
